# Third-party material

LeAnTeX's own code is released under the Apache License 2.0 (`LICENSE`). Parts of it are
derived from [KaTeX](https://github.com/KaTeX/KaTeX), version 0.19.1, which is released under
the MIT licence; its notice is reproduced in full in `LICENSE-KaTeX` and below. Each derived Lean
module names the KaTeX source files it follows in the *References* section of its module
docstring. One table holds numbers measured from KaTeX's fonts, which carry their own licence
(see *KaTeX's fonts* below). LeAnTeX does not include the fonts.

## Derived from KaTeX's fonts

| LeAnTeX | What | Source |
|---|---|---|
| `LeAnTeX/Data/FontAdvances.lean` | the advance widths of the characters of KaTeX's twenty fonts, measured by `tools/gen-advances.mjs` (numbers only; no outline or other font data) | KaTeX 0.19.1's `fonts/*.woff2` |

KaTeX's repository is released under the MIT licence, but the font files themselves state (in
their `name` table, read from the 0.19.1 `woff2` files): "Copyright (c) 2009-2010, Design
Science, Inc. (<www.mathjax.org>) Copyright (c) 2014-2018 Khan Academy
(<www.khanacademy.org>), with Reserved Font Name KaTeX_Main. This Font Software is licensed
under the SIL Open Font License, Version 1.1." (each face names its own Reserved Font Name,
`KaTeX_AMS`, `KaTeX_Size1`, …). LeAnTeX contains no Font Software; it records these notices
because one table is measured from the fonts, and because a back end that draws the display
list needs the fonts, which it must take with their licence.

## Recorded from TeX and from fonts

| File | What | Source |
|---|---|---|
| `fixtures/text/*.jsonl` | TeX's answers (item lists, line breaks, hyphenation points, box dimensions) recorded by `tools/tex-reference.sh` | LuaLaTeX of TeX Live 2025 with the Latin Modern OpenType fonts (GUST Font License) and the US English hyphenation patterns of hyph-utf8 (`hyph-en-us`: copyright Gerard D.C. Kuiken, "Copying and distribution of this file, with or without modification, are permitted in any medium without royalty provided the copyright notice and this notice are preserved"; it includes Knuth's `hyphen.tex` patterns) |
| `fixtures/font/lm*.jsonl`, `latinmodern-math.jsonl` | numbers read from the Latin Modern fonts by fontTools (metrics, names, character maps, boxes, outline hashes; no outlines) | the Latin Modern fonts of TeX Live (GUST Font License, the LaTeX Project Public License 1.3c with a request to rename modified fonts) |
| `fixtures/font/leantex-test-*` | two small fonts drawn by `tools/test-fonts.py`, and their references | Apache-2.0 (this repository) |

LeAnTeX contains no Latin Modern font file; the font tests read the fonts from a TeX
installation when one is present. The recorded fixtures contain glyph indices and metrics of
those fonts and the hyphenation points the patterns give, not the fonts or the patterns.
