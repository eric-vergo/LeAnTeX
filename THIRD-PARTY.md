# Third-party material

LeAnTeX's own code is released under the Apache License 2.0 (`LICENSE`). Parts of it are
derived from [KaTeX](https://github.com/KaTeX/KaTeX), version 0.19.1, which is released under
the MIT licence; its notice is reproduced in full in `LICENSE-KaTeX` and below. Each derived Lean
module names the KaTeX source files it follows in the *References* section of its module
docstring. One table holds numbers measured from KaTeX's fonts, which carry their own licence
(see *KaTeX's fonts* below). LeAnTeX does not include KaTeX's fonts; it includes fonts of New
Computer Modern (see *Fonts: New Computer Modern*).

their `name` table, read from the 0.19.1 `woff2` files): "Copyright (c) 2009-2010, Design

(<www.khanacademy.org>), with Reserved Font Name KaTeX_Main. This Font Software is licensed
under the SIL Open Font License, Version 1.1." (each face names its own Reserved Font Name,
`KaTeX_AMS`, `KaTeX_Size1`, …). LeAnTeX contains none of KaTeX's Font Software; it records these
notices because one table is measured from the fonts. Its back ends draw KaTeX's faces with New
Computer Modern instead.

## Fonts: New Computer Modern

`fonts/newcomputermodern/` holds 29 font files of New Computer Modern by Antonis Tsolomitis,
package version 8.1.1, from CTAN (<https://ctan.org/pkg/newcomputermodern>), unmodified, with
the package's `README` and `License.txt`; `fonts/MANIFEST.tsv` lists each file's size, SHA-256
and licence, and `fonts/README.md` says which files and why. The package's licence statement
(`License.txt`) reads: "All fonts are distributed under the GUST license except NewCM10-Regular,
all NewCMUncial, and all NewCM*Devanagari which are distributed with GPL3 or later plus Font
Exception (FE) plus Distribution Exception (DE)". Only fonts under the GUST Font License are
included; the excepted files are not part of this repository. Each included font carries its
own notice, for example: "(C) 2019-2026 Antonis Tsolomitis. This work is released under the GUST
Font License -- see http://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt for details." The GUST
Font License is the LaTeX Project Public License 1.3c or later (`fonts/LPPL-1.3c.txt`, copied
verbatim from TeX Live) with a request, not a requirement, to rename modified fonts; none is
modified. The back ends draw glyph outlines of these fonts into SVG pictures, and HTML pages load
the files themselves.

## The TeX-rule math layout

| LeAnTeX | What | Source |
|---|---|---|
| `LeAnTeX/TeXMath/*.lean` | TeX's math layout (Appendix G), its arithmetic, the TFM format and its scaling, the delimiter search | implemented from D. E. Knuth, *The TeXbook* (Chapter 17, Chapter 18's spacing table, Appendix G) and the algorithm *TeX: The Program* documents (§99–§107, §539–§575, §680–§767), cited in each module; no program text transcribed; the spacing table's entries and the style functions are facts of the specification |
| `LeAnTeX/TeXMath/Data/MathCodes.lean` | the class, family and slot of LaTeX's math symbols, delimiters and accents, and the ASCII characters' math and delimiter codes | generated by `tools/gen-math-codes.py` from `fixtures/math-codes/codes.tsv` (above): facts of LaTeX's interface (which slot of which font a command names), no macro text |
| `LeAnTeX/TeXMath/Front.lean` | LaTeX's and amsmath's constructions of `\frac`, `\sqrt[n]`, `\big`, `\operatorname`, `\dots`, `\pmod`, arrows, matrices and the others | written from the behaviour of `latex.ltx`, `amsmath.sty`, `amsopn.sty`, `amstext.sty`, `amsfonts.sty` (LPPL 1.3c) as their sources and LuaLaTeX's recorded boxes show it; no macro text reproduced |
| `LeAnTeX/TeXMath/Setup.lean` | LaTeX's math sizes and the metric file chosen for each family and size | facts of `fontmath.ltx` (`\DeclareMathSizes`) and the font definition files `ot1cmr.fd`, `omlcmm.fd`, `omscmsy.fd`, `omxcmex.fd`, `umsa.fd`, `umsb.fd`, `ueuf.fd`, `amsmath.sty`, `amsfonts.sty` (LPPL 1.3c) |
| `LeAnTeX/TeXMath/Data/Glyphs.lean` | the Unicode character of each slot of the Computer Modern, AMS and Euler metric fonts | facts of the font encodings (OT1, OML, OMS, OMX, the AMS and Euler layouts), established from the METAFONT sources and AFM files of TeX Live's `cm` and `amsfonts` packages, `amssymb.sty` and `unicode-math-table.tex` (LPPL); a list of correspondences, no font data |

**The metric files themselves are not included**, nor anything derived from them: the Computer
Modern fonts' metric files (`cmr`, `cmmi`, `cmsy`, `cmex`, `cmbx`, `cmmib`, `cmbsy`; TeX
Live's catalogue: Knuth's licence) and the AMS and Euler fonts' (`cmex7`–`cmex9`, `msam`,
`msbm`, `eufm`, `eufb`; TeX Live's catalogue: SIL Open Font License). The TeX installation the
tests run against holds no statement of the terms beside the metric files, so redistributing
data derived from them was not established as allowed; the layout reads them at run time from a
TeX installation the user has (`docs/math-boxes.md`). Formulas laid out by this layout are drawn
with New Computer Modern Math (*Fonts: New Computer Modern* above).
