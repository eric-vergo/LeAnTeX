# Third-party material

LeAnTeX's own code is released under the Apache License 2.0 (`LICENSE`). Parts of it are
derived from [KaTeX](https://github.com/KaTeX/KaTeX), version 0.19.1, which is released under
the MIT licence; its notice is reproduced in full in `LICENSE-KaTeX` and below. Each derived Lean
module names the KaTeX source files it follows in the *References* section of its module
docstring. Three tables hold data that comes from KaTeX's fonts, which carry their own licence:
two are KaTeX's own data files, and one is measured here (see *Data from KaTeX's fonts* below).
LeAnTeX includes no font file of KaTeX; it includes fonts of New Computer Modern (see *Fonts:
New Computer Modern*).

## Data from KaTeX's fonts

| LeAnTeX | What | Source |
|---|---|---|
| `LeAnTeX/Data/FontMetrics.lean` | KaTeX's table of glyph metrics: for each character of each of its faces the height, depth, italic correction, skew and width | KaTeX 0.19.1's `src/fontMetricsData.js` (part of KaTeX's source under the MIT licence), which KaTeX generates from its fonts |
| `LeAnTeX/Data/SvgPaths.lean` | KaTeX's 59 fixed SVG paths (radicals, stretchy arrows, braces, wide accents): outlines | KaTeX 0.19.1's `src/svgGeometry.ts` (part of KaTeX's source under the MIT licence). Its comments give the origin of the paths: the radicals "from glyph U221A in the font KaTeX Main" and in `KaTeX_Size1-Regular` to `KaTeX_Size4-Regular`, the arrows, harpoons and hooks from glyphs of KaTeX Main and KaTeX AMS Regular, the braces from glyphs of `KaTeX_Size4-Regular`, and `overgroup`, the tildes and the hats from "the MnSymbol package (public domain)" |
| `LeAnTeX/Data/FontAdvances.lean` | the advance widths of the characters of KaTeX's twenty fonts, measured by `tools/gen-advances.mjs` (numbers only; no outline) | KaTeX 0.19.1's `fonts/*.woff2`, read by this repository's tool |

KaTeX's repository is released under the MIT licence, and the first two tables are files of its
source. The font files themselves state (in their `name` table, read from the 0.19.1 `woff2`
files): "Copyright (c) 2009-2010, Design Science, Inc. (<www.mathjax.org>) Copyright (c)
2014-2018 Khan Academy (<www.khanacademy.org>), with Reserved Font Name KaTeX_Main. This Font
Software is licensed under the SIL Open Font License, Version 1.1." (each face names its own
Reserved Font Name, `KaTeX_AMS`, `KaTeX_Size1`, …). This notice is recorded here because the
three tables hold data of those fonts: metrics, the outlines of the glyphs named above as
KaTeX's source carries them, and advance widths. LeAnTeX contains no font file of KaTeX and no
other outline of its fonts, and uses none of the Reserved Font Names for a font of its own; its
back ends draw KaTeX's faces with New Computer Modern instead, and KaTeX's fixed paths as
KaTeX gives them.

## Fonts: New Computer Modern

`fonts/newcomputermodern/` holds 29 font files of New Computer Modern by Antonis Tsolomitis,
package version 8.1.1, from CTAN (<https://ctan.org/pkg/newcomputermodern>), unmodified, with
the package's `README` and `License.txt`; `fonts/MANIFEST.tsv` lists each file's size, SHA-256
and licence, and `fonts/README.md` says which files and why. The package's licence statement
(`License.txt`) reads: "All fonts are distributed under the GUST license except NewCM10-Regular,
all NewCMUncial, and all NewCM*Devanagari which are distributed with GPL3 or later plus Font
Exception (FE) plus Distribution Exception (DE)". Only fonts under the GUST Font License are
included; the excepted files are not part of this repository. Each included font carries its
own notice, for example: "(C) 2019-2026 Antonis Tsolomitis. This work is released under the GUST
Font License -- see http://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt for details." The GUST
Font License is the LaTeX Project Public License 1.3c or later (`fonts/LPPL-1.3c.txt`, copied
verbatim from TeX Live) with a request, not a requirement, to rename modified fonts; none is
modified. The back ends draw glyph outlines of these fonts into SVG pictures, and HTML pages load
the files themselves. The pictures and pages of `examples/` are such output: they hold the
outlines of the glyphs they show (and the paths of *Data from KaTeX's fonts* where a formula
uses them), and the pages name the font files by their own names.

**The metric files themselves are not included**: the Computer Modern fonts' metric files
(`cmr`, `cmmi`, `cmsy`, `cmex`, `cmbx`, `cmmib`, `cmbsy`) and the AMS and Euler fonts'
(`cmex7`–`cmex9`, `msam`, `msbm`, `eufm`, `eufb`) are read at run time from a TeX installation
the user has (`docs/math-boxes.md`). The terms known for them: for Computer Modern, Knuth's
statement that the fonts may be used freely and must not be changed under the same names (TeX
Live's catalogue lists it as Knuth's licence); for the AMS and Euler fonts, TeX Live's catalogue
names the SIL Open Font License. No formal licence text accompanies the metric files in the TeX
Live installation the tests run against. What the repository does hold of their numbers is in
the recorded typeset output of `fixtures/math-box/` (above): the width, height and depth of
each character a recorded formula uses, at the sizes it was set at, as TeX's output carries
them. Formulas laid out by this layout are drawn with New Computer Modern Math (*Fonts: New
Computer Modern* above).
